# The Daily List

A notebook-style to-do app built with vanilla HTML, CSS and JavaScript.

🔗 **Live demo:** https://daily-list-todo-app.netlify.app

## Features
- Add, edit (double-click) and delete tasks
- Filter by All / Active / Completed
- Progress bar for completed tasks
- Tasks saved in localStorage
- Export list as a .txt file
- Keyboard accessible, respects reduced-motion settings

## Tech
HTML5, CSS3 (custom properties), vanilla JavaScript
